# 初中数学错因分类

分类用于保持输出一致，不用于给学生贴标签。记录具体知识点与行为证据；无法可靠归类时保留 `UNCLASSIFIED`。

| 代码 | 类别 | 可观察线索 | 优先诊断方式 |
|---|---|---|---|
| `CONCEPT_MEANING` | 概念含义混淆 | 把定义条件替换成相似但不同的性质 | 用正例、反例或边界例判断 |
| `RELATION_MODEL` | 数量关系建模错误 | 式子中的量与题意对应不上 | 让学生逐项解释式子含义 |
| `CONDITION_MISSED` | 条件遗漏或误读 | 未使用关键条件、单位或取值范围 | 删除/恢复条件比较结论变化 |
| `REPRESENTATION` | 表征转换失败 | 图、表、文字和代数式之间映射错误 | 用更简单对象做双向转换 |
| `STRATEGY_CHOICE` | 策略选择不适用 | 方法本身正确但不满足适用条件 | 比较两个方法的适用边界 |
| `RULE_OPERATION` | 规则或运算步骤错误 | 移项、去括号、通分、符号等稳定出错 | 单步骤微题并要求说明依据 |
| `CALCULATION` | 数值计算错误 | 方法与结构正确，局部算术不一致 | 心算小题或逆运算检查 |
| `TRANSCRIPTION` | 抄写或符号复制错误 | 前后行无理由改变数字、符号或变量 | 让学生逐项对照原式 |
| `VERIFICATION` | 验算与监控不足 | 结果违反范围、单位或代回不成立 | 要求估算、代回或边界检查 |
| `UNCLASSIFIED` | 暂未分类 | 证据不足或出现新模式 | 保留原始描述并增加诊断证据 |

## 使用规则

1. 先写可观察行为，再选择代码。
2. 一次错误可以有多个候选，但第一轮最多三个。
3. `CALCULATION` 与 `CONCEPT_MEANING` 不得仅凭最终答案区分。
4. “粗心”不是分类。将其拆解为 `TRANSCRIPTION`、`CALCULATION`、`CONDITION_MISSED` 或 `VERIFICATION` 的可观察行为。
5. 状态随证据更新，不能把分类保存为永久学生标签。
