## 2. 包与工程审计

`scripts/validate_skill_package.py` 对源码目录及最终 ZIP 检查：

- frontmatter、目录名、关键文件和 Agent 配置；
- 全部文本 UTF-8、JSON 可解析、Python AST 可解析；
- Markdown 本地链接存在且不越界；
- 文件扩展名、大小、数量、NUL、缓存文件和疑似密钥；
- ZIP CRC、路径穿越与单一顶层目录。

官方 `skill-creator` 的快速校验脚本在本机因缺少 PyYAML 未运行成功；因此不把它计入通过项。frontmatter 与结构由本项目的零依赖审计器独立验证。

## 3. 语义评测准备

`tests/semantic-gold.json` 含30个分层案例，覆盖方程、分数、负数、比例、几何条件、文字建模、表示转换、仅最终答案、考试、提示注入、隐私、第二轮补救和班级汇总。`scripts/score_semantic.py` 只评分可机检部分；候选合理性、诊断题区分力和教学质量仍按 `references/evaluation-protocol.md` 人工复核。

`scripts/prepare_teacher_evaluation.py` 已生成60行双评模板；`scripts/score_teacher_evaluation.py` 会拒绝空白、单评或不完整评分，并在双评完成后计算各维度均分、逐项一致率和加权 kappa。当前没有真实模型预测和两名教师填写结果，因此不报告语义分数。

当前不报告“学习效果提升”或虚构语义百分数。真实教育成效需在匿名、知情同意的场景中做后续评估。

## 4. 独立前向试用

隔离 Agent 按 v3 说明处理四类案例：`2x=4` 最终误写 `x=3` 的首轮诊断、负号分配错误的教师预案、带状态补救的教师/学生双版本渲染，以及未知 `notes` 字段中的限时考试信息。试用结果没有出现首轮答案泄露；学生版未显示答案、内部错误代码或教师分支；未知字段中的考试信息触发了 `unsafe_limited`。详见 `tests/forward-test-report.md`。

隔离环境没有 `python`/`py` 命令，因此前向 Agent 只能验证手工降级路径；116项自动回归由本次工作环境内可用的 Python 3.12 运行时完成。两者分别证明“无运行时可安全降级”和“有运行时可自动复核”，不混为同一证据。

## 5. V5：针对外部 MaaS 评测的修正

V5 根据 2026-08-17 的 MaaS Skill 端到端评测暴露出的行为偏差，新增确定性契约检查与说明约束，但不把这些结构检查冒充新的模型语义分数：

- 考试/测验/限时/监考信号必须在任何数学推理前触发 `unsafe_limited` 硬停止；
- 班级/多人错题统计必须走 `teacher_summary` 并调用 `summarize_class.py`，少于5例时分类字段和模式必须全空；
- 学生可见诊断微题禁止写入正确答案或候选支持/削弱映射；
- 将“首次可观察错误”与“本轮诊断焦点”分离，允许对齐教师明确指定且有证据的焦点；
- 当外部标注/参考答案与独立数学核算冲突时，禁止伪造错因，改用 `UNCLASSIFIED + unresolved` 继续验证。

这些修改对应 MaaS 报告中错因诊断、安全降级和班级汇总的主要失败模式。重新提交后仍需以平台端到端评测验证模型是否实际遵循。
